# Hopson RPG #

Hopson RPG is an ASCII RPG designed in C# and is also being used as a learning platform.

Initially made by Matthew Hopson as a project to learn C#, UI and other major improvements by Liam Newman.

### Compiling ###

Builds are currently not compiled. You will have to compile a build yourself.

You will need:
* Visual Studio (2010-Latest)

It's as simple as clicking build.
